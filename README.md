# Hruška
Android aplikace pro rozvozové linky.

## Funkce
- Výběr linky
- Úprava názvu linky ikonou tužky
- Adresy, poznámky a navigace Google Maps
- Vyhledávání zastávek a volitelné prohledání poznámek
- Lokální ukládání do SharedPreferences

## APK
Po každém push do main otevřete Actions → Android APK → poslední běh → Artifacts → Hruska-debug-apk.
